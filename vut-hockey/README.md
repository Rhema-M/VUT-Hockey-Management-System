# VUT Hockey

VUT Hockey is a portable university hockey club website and management system. It uses the requested architecture: Vanilla HTML/CSS/JavaScript, a Python Flask REST API, and MySQL.

## Features

- Public pages for fixtures, results, teams, news, gallery, about, and contact
- Dynamic content loaded from Flask endpoints
- MySQL schema with foreign keys and indexes
- JWT authentication for administrators
- Admin CRUD for teams, players, fixtures, results, news, gallery, messages, and settings
- Validated image uploads stored under `backend/uploads/`
- Loading, error, and empty states that do not invent club information

## Local setup

Requirements: Python 3.11+, MySQL 8+, and a virtual environment.

```bash
cd backend
python -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env
```

Set the MySQL connection values and a long random `JWT_SECRET` in `backend/.env`.

Create the database:

```bash
mysql -u root -p < database/schema.sql
```

The initial administrator must be created through `database/seed.sql` after replacing `REPLACE_WITH_WERKZEUG_PASSWORD_HASH` with a hash generated by:

```bash
python -c "from werkzeug.security import generate_password_hash; print(generate_password_hash('your-password'))"
```

Start the application from the project root:

```bash
python -m backend.app
```

Open `http://localhost:5000`. The admin login is at `/admin/login.html`.

## API

Public read endpoints include `/api/teams`, `/api/players`, `/api/fixtures`, `/api/results`, `/api/news`, `/api/gallery`, and `/api/settings`. Contact submissions use `POST /api/contact`.

Admin login is `POST /api/auth/login`. Protected requests send `Authorization: Bearer <token>`. CRUD routes use the resource names under `/api/teams`, `/api/players`, `/api/fixtures`, `/api/results`, `/api/news`, and `/api/gallery`. Message and settings management is under `/api/contact` and `/api/settings`.

All responses use `{ "success": true, "data": ... }` or `{ "success": false, "error": "..." }`.

## Portability notes

The project does not depend on Replit services, a Replit database, or frontend frameworks. Clone the `vut-hockey` directory, install `backend/requirements.txt`, configure MySQL and `.env`, and run Flask from a normal terminal.
